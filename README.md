# DataForSolution — Learning, Tools, and Curated Engineering Projects

DataForSolution is the public learning and project site for work spanning healthcare technology, medical imaging, software engineering, data/AI engineering, and responsible AI.

## Current public surfaces

- [Structured learning](https://dataforsolution.github.io/learn/) in data science and applied technology
- [Curated portfolio](https://dataforsolution.github.io/projects/) with ten reviewed, reproducible projects
- [Tool Lab](https://dataforsolution.github.io/toolkits/) with clearly labeled working and planned browser utilities
- [Articles and references](https://dataforsolution.github.io/blog/) grounded in publisher, project, and official documentation links

The canonical project corpus is maintained in [`DataForSolution/Data-Solution/portfolio`](https://github.com/DataForSolution/Data-Solution/tree/Master/portfolio). Historical coursework, disconnected notebooks, copied reference material, and projects with unsupported claims are not presented as equivalent to that portfolio.

## Local build

```powershell
bundle install
bundle exec jekyll build
```

GitHub Pages is the canonical production host and builds from `main` at the repository root. Generated `_site` output is intentionally not committed.

## Scope and safety

Healthcare and medical-imaging material is educational and research-oriented. It is not a clinical, diagnostic, or treatment system. Working tools state their privacy and functional boundaries; planned tools remain labeled as planned.

DataForSolution is part of the broader [OraDigit Technology](https://www.oradigit.com) ecosystem and is maintained by [Lissan Liben](https://www.linkedin.com/in/lissan-analytic).
