    Classification evaluation

    Enter four non-negative whole-number counts.
    How this is calculated
    Accuracy
    (TP + TN) / all observations
    Precision / PPV
    TP / (TP + FP)
    Recall / sensitivity
    TP / (TP + FN)
    Specificity
    TN / (TN + FP)
    F1
    2TP / (2TP + FP + FN)
    NPV
    TN / (TN + FN)
    Balanced accuracy
    (sensitivity + specificity) / 2
    Prevalence
    (TP + FN) / all observations
